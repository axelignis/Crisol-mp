1. **Create `src/lib/actions/piece-actions.ts`** with 'use server' directive. All functions:
   - Call `await createClient()` from `@/lib/supabase/server`
   - Check `await supabase.auth.getUser()` and throw if not authenticated
   - Validate input with Zod before any DB operation

   Export these server actions:

   a) `savePieceDraft(productId: string | null, data: PieceStep1Data)`:
      - Zod schema: type enum('jewelry_unique','jewelry_series','decorative'), title min 3 max 200, description max 2000 optional, base_price int min 0, category_id string uuid nullable
      - If productId is null: INSERT into product with status='draft', generate slug from title via `slugify()`, lookup artisan.id from user_id, set is_unique = (type === 'jewelry_unique')
      - If productId exists: UPDATE product WHERE id = productId (verify artisan owns it via RLS)
      - Return the product id

   b) `saveVariants(productId: string, variants: VariantFormData[])`:
      - Zod schema: array of { id optional uuid, size string nullable, material string nullable, color string nullable, stones string nullable, price_modifier int, stock int min 0 }
      - DELETE existing variants for productId that are NOT in the incoming ids array
      - UPSERT each variant: if id exists UPDATE, else INSERT with product_id
      - For jewelry_unique type: force stock=1 on all variants
      - Return updated variants array

   c) `saveMedia(productId: string, media: MediaFormData[])`:
      - Zod schema: array of { id optional uuid, url string url, cloudinary_id string, sort_order int, is_cover boolean }
      - Validate at most MAX_PHOTOS_PER_PRODUCT (10) entries
      - Ensure exactly one is_cover=true (if none set, first becomes cover)
      - DELETE media records for productId NOT in incoming ids
      - UPSERT each media record
      - Return updated media array

   d) `submitForReview(productId: string)`:
      - Call `supabase.rpc('transition_product_status', { p_product_id: productId, p_new_status: 'pending_review', p_actor_id: user.id })`
      - Validate product has at least 1 photo and title before submitting
      - Return updated product

   e) `updatePublishedPiece(productId: string, data: Partial<PieceStep1Data>)`:
      - Per D-06: direct update on published pieces, no state transition needed
      - UPDATE product fields directly (title, description, base_price, category_id, type)
      - Call `revalidatePath('/es/catalogo')` and `revalidatePath('/es/catalogo/${slug}')` for ISR (DISC-05)
      - Return updated product

   f) `getDraftPiece(productId: string)`:
      - SELECT product with variants and media for pre-populating the wizard on return
      - Verify ownership via artisan_id match

   g) `getMyPieces()`:
      - SELECT all products for the current artisan with cover media, ordered by created_at desc
      - Return array for the artisan's pieces list page
