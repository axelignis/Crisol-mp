## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, badge internal padding |
| sm | 8px | Compact element spacing, chip gaps, thumbnail gaps |
| md | 16px | Default element spacing, card padding, form field gaps |

## Interaction Contracts

### Drag & Drop Media Upload (D-04)
- Drop zone: dashed border, 200px min-height, accent border on drag-over.
- Thumbnails: 80x80px grid below drop zone, draggable for reorder.
- Cover photo indicator: gold/accent ring around first thumbnail. Click any thumbnail to set as cover.
- Upload progress: overlay on thumbnail with percentage.
- Delete: X button on hover (top-right of thumbnail). Confirms via Dialog if photo count = 1.

### Variant Table (D-05)
- Inline editable cells. Click cell to edit, blur to save.
- Columns: Tipo (select), Valor (input), Stock (number input), Modificador (number input with +/- prefix).
- Add row: "+" button below table, accent color.
- Delete row: trash icon on hover at row end. No confirmation for draft variants.

### Filter Interactions (D-11, D-12)
- Checkbox groups for tipo, material, ocasion, tecnica.
- Price range: dual-handle slider with min/max CLP labels.
- URL query params: `?tipo=anillo,collar&material=plata&precio_min=10000&precio_max=50000&ocasion=boda&tecnica=filigrana&pagina=1&orden=reciente`.
- Filters apply on change (no "Apply" button). URL updates for shareable state.
- Active filter count badge on mobile "Filtros" button.
- "Limpiar filtros" link when any filter is active.

### Gallery Lightbox (D-14)
- Click main image opens fullscreen dialog overlay.
- Navigation: left/right arrows, keyboard arrow keys, swipe on mobile.
- Close: X button top-right, Escape key, click outside.
- Background: black at 90% opacity.

### Variant Selection (D-15)
- Chips grouped by variant type label (e.g., "Talla:", "Material:").
- Selected chip: accent background + white text. Unselected: secondary background + dark text.
- Selecting a variant updates displayed price dynamically (base + modifier).
- Out-of-stock variants: disabled chip with strikethrough text.
- Low stock: warning badge "Quedan N" appears below variant group when stock <= 5.

### Wizard Auto-Save (D-03)
- Triggers on step advance ("Siguiente" button click).
- Visual feedback: brief "Guardando..." text, then "Guardado" with checkmark for 3 seconds.
- On return to draft: wizard opens at last completed step + 1.
- Browser back/close with unsaved changes: no blocking prompt (auto-save handles it).

### Admin Moderation Actions (D-07)
- "Aprobar": primary accent button. No confirmation dialog (approve is non-destructive).
- "Pedir cambios": secondary button. Requires feedback textarea to be non-empty. Button disabled until text entered.
- "Rechazar": destructive button. Confirmation dialog: "Rechazar pieza -- Esta accion notificara al artesano. Confirmar?"
