4. **Create `src/lib/actions/moderation-actions.ts`** with 'use server':
   All functions check admin role via `supabase.auth.getUser()`.

   a) `approvePiece(productId: string)`:
      - Zod validate: productId as uuid string
      - Call `supabase.rpc('transition_product_status', { p_product_id: productId, p_new_status: 'published', p_actor_id: user.id })`
      - UPDATE product SET approved_by = user.id, approved_at = now(), published_at = now()
      - Fetch artisan email via product.artisan_id -> artisan.user_id -> user.email
      - Send approval email via `resend.emails.send({ from: FROM_EMAIL, to: artisanEmail, subject: ..., react: PieceApprovedEmail({ ... }) })`
      - Call `revalidatePath('/es/catalogo')` and `revalidatePath('/es/catalogo/${product.slug}')` and `revalidatePath('/es/artesanos/${artisan.slug}')`
      - Return { success: true }

   b) `requestChanges(productId: string, feedback: string)`:
      - Zod validate: productId uuid, feedback string min 1 max 2000
      - Call `supabase.rpc('transition_product_status', { p_product_id: productId, p_new_status: 'changes_requested', p_actor_id: user.id })`
      - UPDATE product SET rejection_notes = feedback
      - Send changes-requested email with feedback text
      - Return { success: true }

   c) `rejectPiece(productId: string, feedback: string | null)`:
      - Zod validate: productId uuid, feedback string max 2000 nullable
      - Call `supabase.rpc('transition_product_status', { p_product_id: productId, p_new_status: 'rejected', p_actor_id: user.id })`
      - UPDATE product SET rejection_notes = feedback
      - Send rejection email
      - Return { success: true }

| T-02-09 | E (Elevation) | moderation-actions.ts | mitigate | Verify admin role from JWT via supabase.auth.getUser() + RLS admin policy. Non-admins get 403. |
| T-02-10 | T (Tampering) | moderation-actions.ts | mitigate | Zod validates productId as UUID and feedback as bounded string. State machine RPC rejects invalid transitions. |
| T-02-11 | I (Information Disclosure) | email templates | mitigate | Email contains only piece title, artisan name, and feedback text. No internal IDs or admin identity exposed. |
| T-02-12 | R (Repudiation) | moderation-actions.ts | mitigate | approved_by UUID and approved_at timestamp recorded on product row. Transition logged via state machine function. |
</threat_model>
