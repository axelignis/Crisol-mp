Especificación de API — Crisol

Versión: 1.0 Base URL: https://www.crisol.cl/api Formato: JSON (application/json) Actualizado: Abril 2026

Convenciones generales

Todos los endpoints siguen las siguientes convenciones.

Base URL

https://www.crisol.cl/api

Autenticación

Los endpoints protegidos requieren el header Authorization: Bearer <supabase_jwt>. El token se obtiene de supabase.auth.getSession() en el cliente.

Formato de respuesta

Todas las respuestas son application/json. Las listas siempre incluyen paginación.

{"data": {...}, "error": null}
{"data": null, "error": {"code": "NOT_FOUND", "message": "Pieza no encontrada"}}

Paginación

{"data": [...], "pagination": {"page": 1, "limit": 20, "total": 148, "pages": 8}}

Moneda y locale

Los precios se devuelven en la moneda solicitada via query param currency=CLP|USD. El locale se pasa como locale=es|en.

Códigos de error estándar

Código HTTPError codeSignificado
400VALIDATION_ERRORBody o params inválidos
401UNAUTHORIZEDToken ausente o expirado
403FORBIDDENSin permisos para este recurso

409CONFLICTConflicto de estado (ej: pieza ya publicada)

Pedidos

POST /api/orders Público

Crear pedido

Crea un nuevo pedido para un comprador registrado o invitado. Valida stock, aplica cupón y descuento de puntos, calcula comisión según COMMISSION_CONFIG vigente y retorna el order_id y el client_secret de Stripe para completar el pago.

Body (JSON)
NombreTipoReq.Descripción
items array sí Lista de {product_id|commission_slot_id, variant_id?, quantity}
shipping_address object sí Dirección completa de envío
courier string sí chilexpress | starken | dhl | fedex | pickup
payment_method string sí stripe | crypto | bank_transfer
currency string sí CLP | USD
coupon_code string no Código de cupón a aplicar
points_to_redeem integer no Puntos a canjear (solo compradores registrados)
guest_email string no Requerido si no hay token de sesión
guest_name string no Nombre del comprador invitado
Ejemplo de request
{
  "items": [
    {
      "product_id": "d4f2a1b3-...",
      "variant_id": "v1b2c3-...",
      "quantity": 1
    }
  ],
  "shipping_address": {
    "full_name": "Ana Torres",
    "address_line1": "Av. Providencia 1234, Depto 5B",
    "city": "Santiago",
    "state_province": "Región Metropolitana",
    "country_code": "CL",
    "postal_code": "7500000",
    "phone": "+56912345678"
  },
  "courier": "chilexpress",
  "payment_method": "stripe",
  "currency": "CLP",
  "coupon_code": "PRIMAVERA10",
  "points_to_redeem": 50
}
Ejemplo de respuesta
{
  "data": {
    "order_id": "ord1a2b3-...",
    "status": "pending_payment",
    "subtotal": 185000,
    "shipping_cost": 4990,
    "discount_amount": 19490,
    "commission_amount": 17001,
    "total": 170500,
    "currency": "CLP",
    "stripe_client_secret": "pi_3O...secret_xyz",
    "coinbase_hosted_url": null
  },
  "error": null
}
Posibles errores
  • 400 VALIDATION_ERROR — campos inválidos o faltantes
  • 409 CONFLICT — producto agotado o slot no disponible
  • 422 UNPROCESSABLE — cupón inválido, expirado o sin usos restantes
  • 422 UNPROCESSABLE — puntos insuficientes para canjear

Crea o recupera el Payment Intent de Stripe para un pedido existente. Devuelve el client_secret para inicializar Stripe Elements en el cliente. Si el pedido ya tiene un Payment Intent activo, lo devuelve sin crear uno nuevo.

Body (JSON)
NombreTipoReq.Descripción

Ejemplo de request
{ "order_id": "ord1a2b3-..." }
Ejemplo de respuesta
{
  "data": {

    "amount": 170500,
    "currency": "clp",
    "payment_intent_id": "pi_3Oxxxxxxxxxxxxxxx"
  },
  "error": null

Posibles errores
  • 404 NOT_FOUND — pedido no encontrado
  • 409 CONFLICT — pedido ya pagado
POST /api/webhooks/stripe Webhook

Webhook de Stripe

Recibe y procesa eventos de Stripe. Verifica la firma con STRIPE_WEBHOOK_SECRET antes de procesar. Al recibir payment_intent.succeeded ejecuta: crea PAYMENT, calcula y registra el split, actualiza ORDER a "paid", crea LOYALTY_TRANSACTION si hay comprador registrado, y envía notificaciones.

Nota: Header requerido: Stripe-Signature. Eventos escuchados: payment_intent.succeeded, payment_intent.payment_failed, account.updated
Body (JSON)
NombreTipoReq.Descripción
type string sí Tipo de evento de Stripe
data.object object sí Objeto del evento (PaymentIntent, Transfer, etc.)
Ejemplo de request
{
  "id": "evt_1O...",
  "type": "payment_intent.succeeded",
  "data": {
    "object": {
      "id": "pi_3O...",
      "amount": 17050000,
      "currency": "clp",
      "status": "succeeded",
      "metadata": { "order_id": "ord1a2b3-..." }
    }
  }
}
Ejemplo de respuesta
{ "received": true }
Posibles errores
  • 400 — firma inválida
  • 500 — error procesando evento
POST /api/webhooks/coinbase Webhook

Webhook de Coinbase Commerce

Recibe eventos de Coinbase Commerce para pagos en criptomonedas. Verifica la firma HMAC-SHA256 con COINBASE_COMMERCE_WEBHOOK_SECRET.

Nota: Header requerido: X-CC-Webhook-Signature. Eventos: charge:confirmed, charge:failed
Ejemplo de request
{
  "id": "...",
  "type": "charge:confirmed",
  "data": {
    "id": "cb_charge_...",
    "metadata": { "order_id": "ord1a2b3-..." },
    "payments": [{ "status": "CONFIRMED", "value": { "crypto": { "amount": "0.0015", "currency": "BTC" } } }]
  }
}
Ejemplo de respuesta
{ "received": true }
Posibles errores
  • 400 — firma inválida
