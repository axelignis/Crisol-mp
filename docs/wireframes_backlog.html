Cómo usar este documento: Al iniciar el desarrollo de un módulo, revisar si su pantalla está wireframeada. Si está en "Postergadas", evaluar si el patrón es realmente trivial o si surgieron complejidades nuevas. Si surgieron complejidades → wireframear antes de codear. Si sigue siendo trivial → codear directamente usando el patrón de referencia indicado en la razón.
