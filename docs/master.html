Resumen ejecutivo

Crisol es una plataforma e-commerce multivvendedor de alcance internacional orientada a la venta de joyería artesanal, orfebrería y arte decorativo elaborados por miembros de una familia. Opera bajo un modelo de marca híbrida: identidad unificada Crisol con perfiles de autor visibles por artesano. El administrador (desarrollador del sistema) gestiona la plataforma y percibe una comisión fija automática por cada venta, descontada vía Stripe Connect.

Requerimientos funcionales

RF-01
Gestión de productos
Joyas únicas, en serie, por encargo y arte decorativo. Variantes: talla, material, color, piedras. Piezas vendidas permanecen visibles como portafolio.
RF-02
Multimedia por pieza
Hasta 10 fotos (JPG/PNG/WebP), 1 video y 1 modelo 3D. Visor 3D embebido con @google/model-viewer.
RF-03
Flujo de publicación
Piezas nuevas requieren aprobación del admin. Ediciones menores se publican directamente. Artesano notificado del resultado.
RF-04
Catálogo y búsqueda
Filtros: tipo de pieza, material, rango de precio, ocasión y técnica artesanal. Perfil público por artesano con URL amigable.
RF-05
Piezas por encargo
Artesano publica slots disponibles con precio y tiempo estimado. Comprador reserva y paga el monto completo al confirmar.
RF-06
Carrito y checkout
Disponible para invitados. Política de no devoluciones y aviso de impuestos internacionales visibles antes de confirmar.
RF-07
Pagos y comisiones
Stripe Connect (tarjeta), Coinbase Commerce (cripto) y transferencia bancaria. Split automático: comisión configurable → neto al artesano.
RF-08
Envíos
Cada artesano despacha sus piezas. Cotización automática: Chilexpress + Starken (nacional), DHL + FedEx (internacional). Envío gratis configurable. Retiro en persona.
RF-09
Ciclo de pedido
Pendiente → Pagado → En preparación → Enviado → Entregado. Estados gestionados por el artesano. Notificaciones email + push en cada cambio.
RF-10
Puntos y membresía
1 punto por compra. 2 niveles (umbral y beneficios configurables). Canje como descuento directo en carrito. Acceso anticipado, envío gratis y descuentos en encargos para el nivel superior.
RF-11
Panel del artesano
Gestión de piezas y slots, ventas, estado de pedidos, balance neto, comisiones descontadas, perfil público y notificaciones.
RF-12
Panel del admin
Reportería completa (ventas, comisiones, tráfico, encargos), exportación CSV/Excel/PDF, gestión de artesanos, catálogo, cupones, membresías y reseñas.
RF-13
Funcionalidades comprador
Favoritos, historial, reseñas verificadas, seguir artesanos, panel de puntos y membresía.
RF-14
Blog y contenido editorial
Sección editorial gestionable desde el panel de admin. Soporte para contenido con IA como asistente de redacción.
RF-15
Notificaciones
Email transaccional (Resend) + Web Push para artesanos (nuevos pedidos) y compradores (cambios de estado).
RF-16
Internacionalización
Arquitectura i18n desde el inicio con next-intl. Lanzamiento en español. Hreflang preparado para agregar idiomas sin refactorización.
RF-17
Multi-moneda
CLP y USD con conversión en tiempo real. Precios mostrados en la moneda del visitante.
RF-18
Cupones y promociones
Códigos de descuento (porcentaje o monto fijo) con límite de usos, expiración y reglas de aplicación.
RF-19
Configuración global
COMMISSION_CONFIG versionada: % de comisión, umbral de envío gratis, umbrales de membresía y tasa de conversión de puntos — todo configurable desde el panel.

Decisiones de arquitectura (ADR)

ADR-001Supabase como backend principalAceptada
Alternativas evaluadas: Firebase, PlanetScale + Auth0, Neon + Clerk.
Razón: Resuelve autenticación, base de datos PostgreSQL, storage de archivos y Row Level Security en un solo servicio. Reduce configuración y costos iniciales. Migración a infra propia posible si el proyecto escala.
ADR-002Stripe Connect para split paymentsAceptada
Alternativas evaluadas: MercadoPago, PayPal Marketplace, distribución manual.
Razón: Único gateway con split payments nativos (Transfer API), PCI DSS Level 1 y soporte robusto para marketplace latinoamericano. El costo (2.9% + fee) se absorbe en el porcentaje de comisión.
ADR-003Next.js 14 App Router con ISRAceptada
Alternativas evaluadas: Remix, Nuxt 3, Astro.
Razón: SSG/ISR nativo crítico para SEO de catálogo. React Server Components reduce JS enviado al cliente. Ecosistema más maduro para e-commerce. next-intl e integración con Vercel sin configuración adicional.
ADR-004Cloudinary para multimediaAceptada
Alternativas evaluadas: Supabase Storage solo, AWS S3 + CloudFront, Uploadthing.
Razón: Conversión automática a WebP/AVIF es un RNF crítico para Core Web Vitals. Cloudinary lo resuelve sin código adicional. CDN global incluido. Supabase Storage se usa solo para modelos 3D donde la transformación no aplica.
ADR-005USER como tabla base única (single table inheritance)Aceptada
Alternativas evaluadas: tablas separadas por rol, discriminated union.
Razón: Permite a futuro que un mismo email sea artesano y comprador simultáneamente sin duplicar registros de autenticación. Supabase Auth gestiona el registro; la tabla USER extiende con datos del negocio.
ADR-006SEO_META polimórfica para todos los metadatosAceptada
Alternativas evaluadas: columnas SEO en cada tabla, JSON en la misma entidad.
Razón: Centraliza metadatos SEO y Schema.org JSON de productos, artesanos, categorías y blog posts en una sola tabla. El admin puede editar metadatos de cualquier entidad desde un solo panel sin modificar las tablas de negocio.

Puntos abiertos y pendientes técnicos

Formatos de modelos 3D aceptados (.glb, .gltf, .usdz) — definir al evaluar el pipeline de producción 3D de los artesanos y las herramientas que usarán para crear los modelos.
Porcentaje exacto de comisión — configurable desde el panel de admin. Definir valor inicial antes del lanzamiento.
Umbral de puntos para nivel Premium — configurable desde el panel. Definir valor inicial.
Tasa de conversión de puntos a dinero — ej. 100 puntos = $1.000 CLP. Definir antes de implementar el módulo de fidelización.
Nombres de los niveles de membresía — a definir desde el panel de admin antes del lanzamiento.
Onboarding de artesanos en Stripe Connect — definir el flujo de activación de cuenta Stripe antes de poder despachar pedidos. Bloqueante para el MVP.
Gestión de impuestos internacionales — actualmente se muestra solo un aviso legal. Evaluar si se necesita integración con un servicio de tax compliance (ej. TaxJar) antes del lanzamiento internacional.
